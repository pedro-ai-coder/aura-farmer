# Aura Farmer — Cartoon 2D Game Design

Fast top-down solo roguelite combining auto-combat and deliberate risk-taking. Strategic builds with humorous brainrot flavor, originally inspired by Brotato and Swarm.

Core loop: survive each wave -> collect XP -> choose buffs -> maximize Aura via risky maneuvers -> defeat Big Hater.
Character: Sigma. Independently from Sigma Focus, E triggers FLEX and exposes player to damage.
Enemies: basic NPC, Hater ranged, Beta Bro heavy, Big Hater boss.
Weapons: starting Blaster; Mewing Jaw and Ohio Orbiter unlock through buffs.
Buff themes: Sigma, Alpha, Mewing Streak, Locked In, Drip Check, Bro Has Motion, Six Seven, Absolute Unit.
Victory after five 50s waves, boss on wave five; death restarts.
Cartoon visuals: original vector primitives, rounded shapes, saturated and readable.
MVP has desktop keyboard and Android-tested mobile touch controls. Multiplayer, Discord, persistence and shop are out of scope.
