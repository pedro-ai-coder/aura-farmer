# AURA FARMER — Cartoon 2D Roguelite

Protótipo 0.1 para browser desenvolvido em Phaser 3, TypeScript e Vite.

## Estado

O projeto está em fase inicial e deve ser validado antes de ser considerado jogável. Foco: combate automático, Flex como ação de risco, Aura Meter, buffs e cinco vagas. Primeiro solo; multiplayer e Discord só em fases futuras.

## Executar

Requer Node.js 22 e npm:

```bash
npm install
npm run dev
```

## Validação

```bash
npm run typecheck
npm test
npm run build
```

O Codex deve começar por `docs/CODEX_TASK_001.md` e seguir `AGENTS.md`.

**Não afirmar que a build funciona sem executar os testes e um smoke test em browser.**
